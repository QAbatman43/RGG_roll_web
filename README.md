# RGG Roll Web

Браузерная версия генератора Retro Game Gauntlet Roll Machine на Godot 4.7.

[Открыть генератор](https://qabatman43.github.io/RGG_roll_web/)

## Возможности

- Списки платформ и игр, спецролы, лутбоксы, «Кот в мешке», «Гитман» и «Колесо».
- Три вида глобальных событий: обычные, компетитив и спецролльные. У каждого свой список и свои удалённые пункты.
- Прокрутка с обычной и быстрой остановкой, фильтр по первой букве или цифре, просмотр списка по правому клику.
- Описания пунктов колеса, глобальных событий и лутбокса «Рулетка».
- Ссылки для игровых результатов на YouTube, MobyGames, GameFAQs и HowLongToBeat, где они применимы.
- TTS для выпавшего пункта и отдельное отключение звуков игры.
- Персонализация фона, музыки, цветов, обводки и фона текста пунктов. GIF и видео могут двигаться всегда, только при вращении или только в покое.
- Экспорт и импорт браузерных настроек и прогресса через ZIP в меню настроек.

## Управление

| Действие | Как выполнить |
| --- | --- |
| Начать прокрутку | `Roll` |
| Начать остановку | `STOP` |
| Быстро остановить после разрешённой задержки | `На ультратоненького` |
| Отфильтровать по первой букве или цифре | Поле справа от `Roll`; цифры разрешает чекбокс `Цифры` |
| Посмотреть весь список | Правый клик по кнопке списка |
| Включить озвучку или выключить звук игры | `TTS/OFF` или `MUTE/UNMUTE` |

## Файлы и данные

- `godot_source/` — проект Godot: сцена, GDScript, ресурсы и настройки экспорта.
- `index.html` и `rggweb.*` — опубликованная веб-версия. `godot_source/Web.*` — промежуточные файлы экспорта, которые не добавляются в Git.
- `lists/` — списки, которые читает браузерная версия. Соответствующие исходные списки лежат в `godot_source/lists/`; при редактировании держите обе копии согласованными. Изменение только списков не требует нового экспорта Godot.
- `godot_source/images/cards/` — карточки PNG. Веб-экспорт исключает их из `PCK` и загружает из этой папки по мере обращения.
- `godot_source/audio/` — MP3 и WAV. Веб-экспорт исключает их из `PCK`; браузер загружает звуки параллельно с игрой и подготавливает их до открытия интерфейса. Поэтому первый ролл не ждёт загрузки трека, но первоначальная загрузка страницы длится дольше. Экспорт Windows включает звуки в приложение.
- `tests/` — проверки списков, описаний и браузерных мостов для фона и музыки.

Списки читаются в UTF-8 (с BOM или без) и UTF-16 с BOM. Некоторые файлы глобальных событий уже хранятся в UTF-16LE; переводить все списки в UTF-8 перед публикацией не требуется.

Настройки и удалённые пункты сохраняются локально в браузере. Кнопки `Export` и `Import` в настройках переносят их между браузерами, включая пользовательские фон и музыку. Резервный ZIP не заменяет файлы проекта.

В настройках `Сменить музыку` выбирает один MP3, а `Выбрать несколько` заменяет его набором до 32 MP3 общим объёмом до 90 МБ. При каждом новом ролле без собственной музыки случайно выбирается один трек из набора. Набор сохраняется в браузере и входит в резервный Export/Import.

## Обновление веб-версии

1. Откройте `godot_source/project.godot` в Godot и экспортируйте пресет `Web` в `godot_source/Web.html`. Пресет исключает из пакета карточки, MP3 и WAV.
2. В корне репозитория выполните `.\update-web-export.ps1` в PowerShell. Скрипт копирует свежий экспорт в `rggweb.*`, обновляет `index.html` и сохраняет браузерный код для фона, импорта и экспорта настроек, а также предзагрузки звуков.
3. Запустите проверки: `node --test tests/*.test.cjs`.
4. Добавьте в коммит изменённый код, опубликованные файлы и внешние ресурсы, затем отправьте коммит на GitHub.

Для правок только в `lists/`, карточках или замены существующего аудиофайла с тем же именем новый экспорт обычно не нужен. Если изменились GDScript, список предзагружаемых звуков или другие файлы внутри `PCK`, экспортируйте проект заново и повторите шаги выше.
